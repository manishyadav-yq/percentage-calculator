## 📖 About

Percentage Calculator is a simple desktop application built to make calculating academic percentages easier for students.

Whether you're checking your exam results, calculating your overall percentage, or keeping track of your academic performance, this application provides a straightforward way to do the calculations.

No complicated setup or unnecessary features — just a simple tool designed to get the job done.

## ✨ Features

- 🧮 **Five-Subject Calculation** — Calculate your percentage across five subjects.
- ⚡ **Quick Results** — Get your percentage without doing the calculations manually.
- 💻 **Windows Desktop App** — Run the application directly on a compatible Windows computer.
- 🎯 **Student-Friendly** — Designed with students and everyday academic calculations in mind.
- 📦 **Standalone Executable** — Download the `.exe` file from the GitHub Releases page.

## 📥 Download & Installation

### Step 1: Download

Visit the latest release:

**[⬇️ Download Percentage Calculator v1.0.0](https://github.com/manishyadav-yq/percentage-calculator/releases)**

Under the release assets, download:

### Step 3: Launch

Open the downloaded executable on your compatible Windows computer.

If Windows displays a security warning, verify that you downloaded the file from this official repository before deciding whether to run it.
